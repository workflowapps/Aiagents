Section 01

What actually is an AI agent?

The term gets used loosely. Here are three grounding concepts that will help you make sense of everything else on this page.

01

A chatbot answers. An agent acts.

A chatbot gives you a response. An AI agent takes a goal, works out the steps to achieve it, and executes those steps across multiple tools, systems, and decisions without you having to orchestrate every move.

The core distinction

02

Agents need tools, memory, and goals.

An agent is typically given a large language model as its reasoning engine, a set of tools it can call (search, APIs, calendar, code), some memory of what has happened so far, and an objective. The model decides when and how to use each tool.

What makes it work

03

Autonomy sits on a spectrum.

Some agents always ask you before acting. Others run fully in the background. The right level of autonomy depends on how much the cost of an error matters and how confident you are in what the agent has been trained to do.

Design principle
A useful mental model: think of an agent as a very capable intern with access to your tools. You set the objective and the guardrails; the agent figures out the how. The difference between a good agent deployment and a bad one is usually how clearly the objective and constraints were defined, not the model or the platform.

Section 02

Three types of agent

Most agents in use today fall into one of three categories. Understanding the distinction helps you choose the right platform and set the right expectations.

Type 01: User-driven

Conversational and Copilot Agents

The user is in the loop at every step. You ask, it responds, fetches, summarises, or drafts and waits for your next prompt. Low autonomy, high transparency.
